# Fix Bug

**Agents:** `requirement-analyst` (scope) → `developer` → `qa-automation` → `code-reviewer`

1. Confirm reproduction steps and expected behavior.
2. Root-cause analysis in repo.
3. Minimal fix; add/update automated tests.
4. Review and re-run affected tests.

Obtain implementation approval before code changes if not already given in-session.
