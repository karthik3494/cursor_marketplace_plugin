# Marketplace Publishing

1. Public Git repository with `devflow-ai/.cursor-plugin/plugin.json`
2. Optional multi-plugin: `.cursor-plugin/marketplace.json` at repo root (this repo)
3. Logo at `devflow-ai/assets/logo.svg` referenced in manifest
4. Complete README, CHANGELOG, LICENSE
5. Run `node devflow-ai/scripts/validate-plugin.mjs`
6. Test local install in Cursor
7. Submit at [cursor.com/marketplace/publish](https://cursor.com/marketplace/publish)

Do not claim listed/approved until Cursor confirms review.
